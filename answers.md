1. What is the difference between a function and a procedure in PostgreSQL?
> The difference between a function and a procedure in PostgreSQL is that functions return a value whereas procedures only execute code without returning anything.
2. Can a trigger be executed manually? Why or why not?
> No, a trigger cannot be executed manually because a trigger is a condition on which a certain function is executed. However, the trigger function itself can be executed manually (for testing purposes, for example).

> - Quick access to records
> - Minimizing human error
